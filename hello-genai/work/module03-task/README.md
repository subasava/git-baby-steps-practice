# Python Calculator Project

This is a simple Python calculator project that demonstrates a basic module structure.

## Files

- `calculator.py` contains the `add()`, `subtract()`, and `multiply()` functions.
- `main.py` imports these functions and demonstrates their usage.

## Functions

- `add(a, b)`: returns the sum of two numbers
- `subtract(a, b)`: returns the difference between two numbers
- `multiply(a, b)`: returns the product of two numbers

## Example

```python
from calculator import multiply

result = multiply(10, 5)
print(result)  # 50
```

## Run

```bash
python main.py
```
