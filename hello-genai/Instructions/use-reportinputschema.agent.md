# Use Report Input Schema Tool

Use this instruction when the user needs to generate a valid weekly status report input payload from command-line arguments.

When to use the tool:
- The user wants to create or update a report JSON payload for `tasks`, `milestones`, `risks`, `dependencies`, or `next_week_priorities`.
- The user has already gathered the report data and wants a structured JSON schema output.
- The user wants to quickly turn command-line data into the expected report input format.

Tool to use:
- `tools/reportinputschema.py`

How to invoke it:
- Run:
  `python tools/reportinputschema.py --tasks '<json-array>' --milestones '<json-array>' [optional arguments]`
- Required arguments:
  - `--tasks`: JSON array of task objects
  - `--milestones`: JSON array of milestone objects
- Optional arguments:
  - `--risks`: JSON array of risks or strings
  - `--dependencies`: JSON array of dependency objects
  - `--next-week-priorities`: JSON array of priority strings
  - `--headline`: report headline
  - `--report-date`: report date
  - `--summary`: summary text

Example:
- `python tools/reportinputschema.py --tasks '[{"id":"TASK-101","title":"Finalize sprint planning","status":"Completed","owner":"Alex","priority":"High","due":"2026-09-08","note":"Planning completed."}]' --milestones '[{"id":"MS-01","name":"Migration phase 1","status":"On Track","target_date":"2026-09-30","completion_percent":65}]'`

How to present results:
- Return the JSON payload generated by the tool.
- Keep the response concise and focused on the created report schema.
- If the user asked for a file, save the JSON output to the requested location.
- If values are invalid, clearly explain the invalid JSON input and ask for corrected data.
