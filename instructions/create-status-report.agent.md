# Create Weekly Status Report

Format: Markdown

Sections:
- Accomplishments
- Blockers
- Next week

Rules:
- Use bullet points only
- Keep total length to 20 lines or fewer
- Use a professional tone
- Do not include fluff words or filler language

Output requirements:
- Write concise updates for each section
- Focus on completed work, issues, and planned actions
- Keep language direct and factual
